## Process

1. **Understand the workflow** — Map how the work happens today, including manual steps, edge cases, and the decisions that slow people down.
2. **Design the system** — Turn the real process into clear flows, permissions, interfaces, and a technical shape that can grow.
3. **Build and ship** — Deliver in reviewable stages, test the important journeys, deploy the system, and support the handoff.
